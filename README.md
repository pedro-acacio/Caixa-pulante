# Caixa Pulante (Bouncing Box)

Interactive music box built with [p5.js](https://p5js.org/) + [p5.play](https://p5play.molleindustria.org/): a little ball bounces over colored blocks to the sound of a song.

## How to view

Open `index.html` in your browser — no installation or server required.

## Structure

- `sketch.js` — block physics, ball collision and soundtrack
- `music.mp3` — soundtrack
- `index.html` — loads p5.js, p5.play, p5.sound and the sketch

## Running locally

No external dependencies: the libraries are already included in the repository. Just open `index.html` directly in the browser or serve the folder with any static server (e.g. `npx serve .`).

> The `ssrdarsfahTemplate-main.zip` file in the repository is not used by the project (it is the original template, still zipped) and can be removed.
